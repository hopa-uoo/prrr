КРАСОТА И МАКЕТ (CSS) Создать файл style.css в той же папке. Здесь писать команды, которые меняют внешний вид. /* Сначала пишем КОМУ мы хотим изменить стиль (селектор) */ h1 { /* А внутри фигурных скобок пишем ЧТО изменить */ color: purple; } Цвета и текст: body { background-color: #f0f0f0; /* Цвет фона всей страницы (можно использовать слова: red, blue, или коды #ff0000) */ color: #333; /* Цвет текста */ font-family: Arial, sans-serif; /* Шрифт. В конце всегда пиши sans-serif на случай, если Arial не загрузится */ font-size: 16px; /* Размер шрифта */ text-align: center; /* Выравнивание текста: left, right, center */ } Размеры и отступы (Самое важное в CSS!): div { width: 300px; /* Ширина блока */ height: 200px; /* Высота блока */ /* Отступы: Верх Право Низ Лево (по часовой стрелке) */ margin: 10px 20px 10px 20px; /* ВНЕШНИЙ отступ (расстояние ДО других элементов) */ padding: 15px; /* ВНУТРЕННИЙ отступ (расстояние от текста до края коробки) */ } Совет: margin: 0 auto; — этот трюк центрирует блок по горизонтали Рамки и тени (Объем и стиль): div { border: 2px solid black; /* Рамка: толщина, стиль (solid - сплошная), цвет */ border-radius: 15px; /* Скругление углов (делает углы круглыми) */ box-shadow: 0 4px 8px rgba(0,0,0,0.2); /* Тень (смещение по X, по Y, размытие, цвет) */ } МАКЕТ (Как расставить элементы в ряд или сетку): Это то, что делает сайт похожим на Пинтерест. /* Флексбокс — выстраивает элементы в ряд или колонку */ .container { display: flex; justify-content: space-between; /* Выравнивание по горизонтали: center (центр), space-between (равномерно) */ align-items: center; /* Выравнивание по вертикали */ gap: 20px; /* Расстояние между элементами внутри контейнера */ } /* Грид — создает сетку (как плитка в Пинтересте) */ .grid-container { display: grid; grid-template-columns: 1fr 1fr 1fr; /* 3 колонки одинаковой ширины */ gap: 15px; /* Расстояние между ячейками */ } Эффекты (Анимация при наведении): button { background-color: pink; transition: 0.3s; /* Плавность анимации (0.3 секунды) */ } button:hover { /* :hover срабатывает, когда мышка наведена на элемент */ background-color: purple; color: white; cursor: pointer; /* Меняет курсор на "руку" как у ссылок */ } ПОЛЕЗНЫЕ ШТУКИ ДЛЯ НАСТОЯЩЕГО ПРИЛОЖЕНИЯ: CSS-переменные (чтобы цвет менять в ОДНОМ месте): /* Задаём переменные в начале (в :root, то есть "у корня" документа) */ :root { --bg: #eef5fb; /* имя пишется с двумя дефисами */ --accent: #7fb3d5; --text: #35506b; } /* Используем через var(...) */ body { background-color: var(--bg); color: var(--text); } button { background-color: var(--accent); } /* Если захотите поменять голубой на розовый — поменяете только :root! */ Сброс отступов (чтобы браузер не добавлял лишнее): * { margin: 0; padding: 0; box-sizing: border-box; } /* box-sizing: border-box — ГЛАВНАЯ хитрость! Без неё: width 300px + padding 15px = реальная ширина 330px С ней: padding внутри, ширина остаётся ровно 300px */ Псевдоклассы (состояния элемента): input:focus { /* когда поле активно (в него кликнули) */ outline: none; border-color: blue; } input::placeholder { /* цвет текста-подсказки внутри поля */ color: grey; } button:active { /* когда кнопка нажата (мышку держат) */ transform: scale(0.98); /* лёгкое "вдавливание" */ } Мобильная верстка (mobile-first): /* Самое важное — в HTML добавить строку, БЕЗ неё телефон показывает мелочь: */ /* Ограничиваем ширину карточки, центрируем по горизонтали */ .app { width: 100%; max-width: 420px; /* на телефоне эта строка не мешает, на планшете — не растягивается */ margin: 0 auto; /* центрирование */ } /* Крупные кнопки и поля — чтобы удобно было нажимать ПАЛЬЦЕМ (не меньше ~44px) */ .btn { padding: 15px; font-size: 16px; } Текстовые переполнения (обрезать длинный текст троеточием): .subject { overflow: hidden; /* прячем лишнее */ text-overflow: ellipsis; /* ... в конце */ white-space: nowrap; /* текст в одну строку, без переноса */ }
